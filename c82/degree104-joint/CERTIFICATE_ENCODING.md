# Certificate encoding

The root certificate, verify_best.py and FACTOR_PROVENANCE.json are unchanged round-10 producer release bytes. Each q_rational string in certificate.json is an exact rational weight. Equal-fraction representations preserve the rational values; the verifier checks the pinned release bytes.

The producer's historical encoding comparison tables cover superseded certificates and alternative representations, so they are omitted from this final-certificate note. The authoritative released representations are the q_rational strings in certificate.json itself. No rational value, certificate byte or verifier hash pin is changed by packaging. Historical certificate and encoding paths in producer records describe the external producer archive.
