# Download and verify the proof assets

These four assets are the complete retained producer proofs. They are not the deleted clean-room referee proofs. No unfinished proof is included. Each compressed asset is below 1.9 GB; no splitting or reassembly is needed for this release. If transporting as chunks yourself, concatenate the parts in recorded order and verify the hash of the resulting xz before decompression.

Publication is pending. After the owner creates a release, set RELEASE_TAG to its actual tag. Download into a new directory; no release tag or public asset URL is asserted here.

```sh
mkdir -p downloaded
gh release download "$RELEASE_TAG" --repo rpinho/math-certificates --pattern '*.drat.xz' --pattern ASSETS.json --pattern VERIFY.md --pattern SHA256SUMS --dir downloaded
cd downloaded
shasum -a 256 -c SHA256SUMS
```
