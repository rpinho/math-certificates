# Download and verify the proof assets

These four assets are the complete retained producer proofs. They are not the deleted clean-room referee proofs. No unfinished proof is included. Each compressed asset is below 1.9 GB; no splitting or reassembly is needed for this release. If transporting as chunks yourself, concatenate the parts in recorded order and verify the hash of the resulting xz before decompression.

These assets are in the release [erdos1183-v1](https://github.com/rpinho/math-certificates/releases/tag/erdos1183-v1). Download into a new directory.

```sh
mkdir -p downloaded
gh release download erdos1183-v1 --repo rpinho/math-certificates --pattern '*.drat.xz' --pattern ASSETS.json --pattern VERIFY.md --pattern SHA256SUMS --dir downloaded
cd downloaded
shasum -a 256 -c SHA256SUMS
```

## n=15..20: erdos1183-v4 release archive

The release is [erdos1183-v4](https://github.com/rpinho/math-certificates/releases/tag/erdos1183-v4). Earlier n=11..14 release links above remain historical and unchanged. All twelve headline trees, full colourings and all compressed witness lists already fit below 20 MB each and are in the packet. Only this optional exhaustive rank-screen archive is separate:

| Asset | Bytes | SHA-256 |
|---|---:|---|

Download into a fresh directory from the packet root (for the erdos1183-v4 release):

```sh
mkdir -p downloaded-v4
gh release download erdos1183-v4 --repo rpinho/math-certificates --pattern no_trees.tar.xz --pattern n23_balanced.txt.xz --pattern MANIFEST.json --pattern ASSETS.json --pattern VERIFY.md --pattern SHA256SUMS --dir downloaded-v4
(cd downloaded-v4 && shasum -a 256 -c SHA256SUMS)
```

The release SHA256SUMS binds its archive and metadata; it is separate from the packet seal. Confirm the archive hash above, then copy the downloaded archive into `producer/n15n20/certificates/no_trees.tar.xz`. From `producer/n15n20/`:

```sh
nice -n 10 python3 -B -m tarfile -e certificates/no_trees.tar.xz certificates
nice -n 10 python3 -B src/check.py certificates/search_000000000000_c1_t1.tree.gz 000000000000 1 1
nice -n 10 python3 -B src/replay.py
```

The standard tar archive contains 55,684 uncompressed `.tree` members, about 2.23 GB total. The producer retained 209 direct gzip trees separately, including the twelve headline trees. The checker accepts an extracted `.tree` when the corresponding `.tree.gz` path is absent. Extraction avoids repeatedly scanning an xz archive; reserve about 2.3 GB disk. These are auxiliary exhaustive rank-minimum proofs. The default `producer/n15n20/replay_packet.py` needs no archive and checks all headline trees and every explicit witness. After adding downloaded or extracted files, use a working copy for replay; the original packet’s seal covers only its delivered files.

For direct witness checking the packet supplies `producer/n15n20/src/check.py`: `witness(n, word, colour, threshold, masks)` checks distinctness, bounds, colour, minimum size, and every binary union/intersection. Complete balanced-word coverage is checked by the replay driver. The referee’s own lists are also included in `referee/n15n20/out/`; no witness list exceeds the 20 MB packet limit in its delivered form.

The upper bounds use exact weighted-poset proof trees, with no SAT at n=15..20. The f(20) lower bound of twelve still depends on BMB’s authors’ mixed-level checker, replayed by the referee but not reimplemented; see [WINDOW20.md](referee/n15n20/WINDOW20.md). Without it, 11≤f(20)≤12. Candidate, no human review.

To replay every archived tree without extracting it, run this from `producer/n15n20/` after placing the downloaded archive in `certificates/` (the expected word, colour and threshold are read from each public filename):

```sh
nice -n 10 python3 -B - <<'PY'
import io, re, sys, tarfile
sys.path.insert(0, "src")
from check import tree
count = 0
with tarfile.open("certificates/no_trees.tar.xz", "r|xz") as archive:
    for member in archive:
        match = re.fullmatch(r"search_([01]+)_c([01])_t([0-9]+)\.tree", member.name)
        assert member.isfile() and match, member.name
        word, colour, threshold = match.groups()
        with io.StringIO(archive.extractfile(member).read().decode("utf-8")) as stream:
            tree(stream, word, int(colour), int(threshold))
        count += 1
assert count == 55684
print("ARCHIVE REPLAY PASS", count)
PY
```
