## Dependency-by-dependency audit of v3

| Item | Check and assessment |
|---|---|
| Theorem 1.1 | Depends on all the following combinatorial steps and the rational evaluation. Numerical implication reproduced with Arb; no stronger value claimed. |
| Lemma 2.1, locality | For a 1324 occurrence there is just one inversion. Staircase cells at distance at least two produce inversions. If the occupied window had width two, its extreme cells would have to contain the inversion's two points, while both endpoints of the occurrence occupy the intermediate cell. The column/row parity respectively contradicts value/position order. Inside one cell 132 or 213 is forced. A one-versus-three split between neighbours likewise puts a forbidden triple inside a cell. This proves the two-plus-two assertion. |
| Lemma 2.2, domino criterion | In a column the low ascent must be the entries of relative values 1,2 and the high ascent the entries of relative values 3,4, with position labels interlaced low,high,low,high. Every such choice is 1324 and every occurrence has this form by 2.1. Checked. |
| Equation (1), skew components | Every earlier skew component has larger values than every later component, so an ascent cannot cross components. Checked directly from the definition. |
| Equations (2),(3), strip factors | The skew-indecomposable Catalan component GF is Q=(1-sqrt(1-4z))/2. Fixing the ordered restricted points splits the ordered component sequence uniquely into blocks. For j free points and n component points in a block there are binomial(n+j,j) weak placements. This gives Omega_j and the product over strips, without making two neighbours independent. |
| Remark 2.3 | A nonempty top cell's maximum is a right-to-left maximum, so the top strip is nonempty; only the other external strip can add an empty strip to the medial count. Rotate for a bottom cell. Difference at most one, irrelevant to density. Finite thresholds use total empty strips throughout. |
| Equations (4),(5) | The integer counts sum to m-ceil(alpha*m)+1 and their leaf-weighted sum is ceil(alpha*m). On the rectangle, the nonempty-strip mean is between two and three. The limiting profile is (beta,3-4alpha-3beta,3alpha+2beta-2). Integer positivity for m>=32 follows as in 4.5. Checked algebraically. |
| Lemma 3.1 | A straddled domino point in the low cell has an earlier smaller point, so is not a left-to-right minimum. A straddled domino point in the high cell has a later larger point, so is not a right-to-left maximum. The connecting-cell ascent is inside one component. Therefore requiring all non-leaves to be at component boundaries excludes every 1324. Checked in both orientations. |
| Remark 3.2 | A permutation is skew decomposable at a slot iff all points on its left exceed all on its right. Negating gives a straddling ascent at every internal slot of an indecomposable component. The stated equivalence of the two gap rules follows. The comment about the weaker exact rule is not used in the proof. |
| Corollary 3.3 | Locality reduces the check to one adjacency; a common domino is valid by definition, and the other adjacencies use 3.1 or its reflected version. No occurrence sees both neighbours of a connecting cell. Checked. |
| Definition 3.4 | Weakly increasing placements are exact shuffles of two fixed ordered point sets. Restricted points are sent to the cumulative component boundaries. An actual connecting permutation supplies position and value boundary lists in reverse component order. The two shuffles are independent conditional on that actual connecting permutation, not after summing over it. |
| Lemma 3.5 | When component j gains one point, shift every slot strictly after its left boundary by one. This strictly increasing injection maps every old component boundary to the corresponding new one. It injects admissible placements. Internal component shape never enters this count. Checked. |
| Theorem 3.6 | With c fixed and total size free, component sizes have the product law a_k*z^k/Q(z). Both placement functions increase in every size, even when one reads the vector in reverse. Chebyshev association in one coordinate and induction give Harris. Truncate the functions then use monotone convergence; their polynomial growth has finite moments for z<1/4. Multiplying the normalized expectation inequality gives the single denominator Q^c. Checked. This would fail as a product-measure proof if total connecting size were fixed. |
| Remark 3.7 | The Harris comparison is between GF values at a fixed positive z. It is not a coefficientwise inequality in z. The subsequent radius argument only uses values at z0. Checked. |
| Lemma 4.1 | A nonnegative q-series evaluated at q=exp(w) has convex log, by the variance identity. A nonnegative strip profile preserves convexity, and the linear -kappa*w term does not affect it. The q-bracket has opposite derivative signs and hence contains a global minimum. The q-radius is 1/Q(z) because fixed j differentiation only adds a polynomial in component count. Checked for the nonnegative profiles used here. |
| Proposition 4.2 | For a zero-leaf profile, the saddle is qQ=kappa/(gamma+kappa). Substitution and subtraction of kappa*log Q gives the binomial entropy exactly. Checked. |
| Lemma 4.3 | The local coordinate map (x,y)->(-y,-x), followed by translation/reindexing, changes column to row, 213 to 132, right-to-left maxima to left-to-right minima, and value cuts to position cuts. The phrase that the one-sided infinite staircase is fixed needs local reindexing; the actual use is only the bijection of the two finite domino orientations. That bijection and strip preservation are valid. |
| Lemma 4.4 | Restrict extra leaves to component boundaries: an identity injection reduces freedom. Splitting a strip this way cannot destroy an empty strip. BBEP's strong coefficientwise log-convexity then lowers the product by equitable redistribution. Removing excess empty strips spreads the leaf vector and is a succession of transfers from a larger to a smaller part, each lowering the product. This establishes a common threshold profile. Checked, conditional on BBEP Proposition 18 (arXiv Proposition 7.3), whose transfer inequality follows from the coefficientwise log-convexity of the binomial sequence. |
| Proposition 4.5 | For fixed k the staircase has a polynomial number of possible griddings of an n-point permutation. Thus the gridded GF converges wherever the ungridded GF converges. Its values dominate F_{k,m}; a positive limiting exponent contradicts boundedness in m for a sufficiently large fixed k. The same threshold coefficient J_m serves both neighbours, so no independently chosen profiles are paired. BBEP's coefficient lemma gives c_m/m->kappa. Ceilings change all profiles by O(1), so their normalized limits are f. The advertised exponential family size is imported from BBEP. The v3 argument uses two substantial published BBEP inputs: the growth 27/4 of balanced domino families with both lower thresholds, and the coefficient-extraction lemma for nonnegative powers. The former uses polynomial pigeonholing and a rotation/arch-concatenation injection; the latter uses a positive saddle with aperiodic positive coefficient series. I have checked the relevant statements against the full BBEP source and the way v3 invokes them. This audit does not claim a fresh proof of every result in BBEP's 35 pages.

## Withdrawn versions: what is established and what is not

**v1:** v2's abstract comments explicitly identify the failure. In [v1 equation (43) and Proposition 7.2](https://arxiv.org/html/2608.20292v1), J=A-2*Ent, where A is an infimum of affine functions of the profile and is concave. The known concave expression is therefore **A=J+2*Ent**, not J-2*Ent. Subtracting the concave entropy term from A does not establish concavity of J. Moreover, a transfer summing over all strip orderings controls an average (or a maximal ordering after a correct asymptotic argument); a uniform lower bound for each actual neighbouring cell requires a minimum over its fixed ordering. A sum divided by the number of orderings does not supply such a minimum. The vertex minimization of v1 Proposition 7.2 and Corollary 7.3 is therefore not justified. Its 10.617 is withdrawn, as v3 reiterates. The exact ordering control is recorded below.

**v2:** the [v3 arXiv Comments](https://arxiv.org/abs/2608.20292v3) identify two withdrawal causes: pairing need not make the two cells of a member agree, and the Appendix F argument count checks only arc endpoints. Our candidate needs only per-cell bounds with possibly different boundary corrections, and its Rouché proof bounds the entire contour. Both AI reviewers found no use of either failed assertion. The exact leaf/block marking and four-series marginal prototype agree with direct enumeration on the computed finite range, but this does not verify the removed tilted-family continuation, concentration or uniform-profile theorem. `V2_DIAGNOSIS.md` separately records a rational counterexample to the printed normalization in Lemma 5.11; its appendix already repairs that factor. This is distinct from the documented withdrawal causes and is not a disproof of the headline number. The historical-diagnosis correction does not accept the full withdrawn route as a proof input.

Credit for the rebuilt marginal equations, kernel evaluations and local algebraic setup belongs to v2 Proposition 5.2, equations (18)–(21), and Corollary 5.5. Credit for the retained two-axis relaxation and Harris argument belongs to v3. BBEP supply the structural, concentration, concatenation and coefficient inputs. Lemma 2.1 of FIRST_MOMENT_PROOF.md now spells out the inverse-map value order from BBEP Propositions 3.2–3.4; `check_value_word.py` checks it on every 213-avoiding upper cell through n=9.

No encoding based on the withdrawn joint ordering/entropy argument is accepted for scaling. The prototype here tests marginal strips against actual dominoes and retains the Harris separation; it does not use the withdrawn joint transfer or tilted-profile theorem.

The exact ordering control is `artifacts/ordering_counterexample.json`. For a two-component connecting cell of total size three, there are the two size vectors (1,2) and (2,1). A free/restricted word L N L L has respectively 26 and 23 placements; L L N L has 23 and 26. Both have the same unordered strip profile {1,2}, and each is realized by actual 132-avoiding neighbour cells along the required axes. With reverse component reading on the other axis the joint counts are 1196 for the first/first pair and 1205 for the first/second pair. Thus a profile-only joint count is not defined; replacing it by an average can overcount an actual pair. This does not falsify the Harris lower bound. The separately written (same agent) integer verifier checks the cells and all counts, and rejects corrupted totals.

## Implementation control

The first C++ all-avoider generator's n=5 OEIS count check exposed an invalid prefix shortcut: a small point arriving after an old peak cannot be used as the earlier point of a 132. The shortcut was replaced by a direct ordered-pair scan with the appropriate earlier prefix minimum. This was a generator implementation failure, not an accepted counterexample to the strip encoding; the failed run is retained as `brute10.jsonl`/stderr on the pod. Only a generator matching the complete known counts may be used in the gate.
